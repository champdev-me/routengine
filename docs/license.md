# License

## Free

For personal, non-commercial use on your own PCs. It needs no key and sends nothing. Using RoutEngine for work or in a business needs a Pro license.

Free includes up to 3 apps, per-app routing and fallback, VPN and Tailscale adapters, combining adapters, live speeds, today's data, a speed limit on one app and a data cap on one app.

## Buying

1. In RoutEngine open **Settings**. Under **This PC** is your machine code, for example `ABCD-EFGH-JKLM`. Press **Copy**.
2. Email **sales@routengine.net** with the plan you want and the machine code.
3. We reply with how to pay.
4. After you pay, send us a screenshot of the payment.
5. We check it and email your license key within 24 hours, usually sooner.
6. In **Settings**, paste the key into **License key** and press **Activate**.

All sales are final, so try the free edition first. See the [refund policy](https://routengine.net/refund.html) and the [terms](https://routengine.net/terms.html).

## Machine code and moving to a new PC

A license works on the PC whose code you sent. A key does not work on another PC. To move a lifetime license to a new PC, email sales@routengine.net with the new PC's machine code.

## The weekly online check

Pro verifies your license online. RoutEngine checks by itself about once a day. It must succeed at least once every 7 days.

- No internet for a few days is fine.
- After 7 days without a successful check, Pro pauses and the free edition runs. Pro returns at the next successful check.
- The check sends your license key, machine code, program version and a fingerprint of the program file. See [Privacy](privacy.md).

## If the license data is changed

RoutEngine keeps your license key file and the licensing server's last signed answer on your PC. If the key file is changed or damaged, if the saved answer is changed, or if the program file has been modified, **Start is blocked** and the window says why. See [Troubleshooting](troubleshooting.md#start-is-blocked) for what to do.

Pro also pauses, without blocking Start, if the PC clock is set back.

Such an event is reported to the licensing server. See [Privacy](privacy.md).

## Removing a license

In **Settings** press **Remove license** to return to the free edition on that PC.
