# Security

## Report a vulnerability

Email **sales@routengine.net** with the subject `Security`. Do not open a public issue for a security problem.

Please include what you found, the RoutEngine version, your Windows version, and the steps to reproduce it. We reply as soon as we can.

We ask that you give us a reasonable time to fix a problem before you publish it, and that you test only on your own PC and your own license. Do not run tests against routengine.net or the licensing server that put load on it or reach other people's data.

## What is in scope

- The RoutEngine program and installer.
- The licensing and update checks, and the signatures they rely on.

## Supported versions

The latest release. Updates are signed and RoutEngine offers them in the app.
